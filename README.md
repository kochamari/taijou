# 帯状疱疹ワクチン補助 年齢判定デモ

スマホのカメラでカルテを写し、生年月日をOCRで読み取って令和7年度の帯状疱疹ワクチン補助対象年齢かを判定するシンプルなWebページです。PWAやバックエンドは含まず、静的ファイルとしてそのままホスティングできます。

## 使い方

1. `python -m http.server 8000` などでローカルサーバーを起動します。
2. ブラウザで `http://localhost:8000` にアクセスします。
3. カメラの利用許可を与え、カルテの生年月日欄を映した状態で「この画面を読み取る」を押すとOCRを実行します（遠目・ボケ気味でも内部で拡大＆二値化してから認識します）。
4. カメラが使えない／写り具合を確認したい場合は「画像ファイルで試す」にカルテ写真をアップロードすると、元画像と前処理後プレビューを並べて表示し、そのままOCRします。
5. 読み取りが難しい場合は「生年月日を手入力」欄で日付を入力して判定できます。

## 実装メモ

- UI は [Pico.css](https://picocss.com/) のCDN版を利用しています。
- OCR には [Tesseract.js](https://tesseract.projectnaptha.com/) のCDN版（日本語 + 英数字モデル）を利用し、tessdata の CDN パスを明示して日本語を高精度でロードします。
- カメラフレームやアップロード画像を 3x まで拡大し、アンシャープ + ガンマ補正の後に Otsu 二値化でコントラストを最大化してからOCRします。遠距離・軽いボケ・影がかかるケースでも画素を立て直してから認識します。前処理結果をプレビュー表示するので、OCRに渡される画素を目視できます。
- OCR文字列はNFKC正規化で全角数字・全角スペース・長音記号の揺れを吸収し、昭和42年9月6日のように段落が崩れた書式でも日付を抽出しやすくしています。PSM 4/6/12 で複数回認識し、列・行・疎なレイアウトのいずれにも当たりやすくしています。
- 令和7年度の対象生年月日リストを配列としてコードに埋め込み、OCRで取得した日付もしくは手入力の日付を照合しています。

## 注意

- カメラアクセスとOCRは端末の性能・照明環境に依存します。読みにくい場合は手入力で補ってください。
- インターネット接続がない環境ではCDNのライブラリが取得できません。その場合はライブラリをローカルに配置してください。
